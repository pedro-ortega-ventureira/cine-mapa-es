# Aulós Heading Repair

Plugin reversible para la instalación de staging de Aulós. Usa el filtro
oficial `botiga_entry_header` para retirar el título técnico de las páginas
que ya contienen un `H1` editorial. En la portada convierte el nombre del sitio
de `h1.site-title` a `p.site-title`, conservando enlace, clase y presentación.

Para revertir, desactivar el plugin. No modifica contenido ni metadatos.
